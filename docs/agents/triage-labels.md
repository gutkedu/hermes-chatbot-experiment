# Triage labels

| Papel canônico | Label no GitHub | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Precisa de avaliação do mantenedor |
| `needs-info` | `needs-info` | Aguarda informação do autor |
| `ready-for-agent` | `ready-for-agent` | Totalmente especificada e pronta para um agente AFK |
| `ready-for-human` | `ready-for-human` | Exige implementação ou decisão humana |
| `wontfix` | `wontfix` | Não será executada |

Quando uma skill mencionar um papel, use a label correspondente nesta tabela.
